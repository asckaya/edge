💻 在 Clash Verge Rev / Mihomo 中如何实时看源头 URL 与泄露日志？
方法 1：使用 Clash Verge Rev 的“日志 (Logs)”与“抓包 (Connections)”

步骤 1：打开客户端的“连接 (Connections)”界面
在左侧边栏点击 连接，勾选 实时刷新。这里会展示每一个发起请求的 进程名称（如 chrome.exe）、源头请求 Host/URL 以及命中的 Rule 规则。

步骤 2：在“日志 (Logs)”中筛选 [DNS]
将日志级别切至 Debug 或 Info，在搜索框中输入 [DNS]。系统会输出形如：
[DNS] resolve target-domain.com from nameserver 223.5.5.5 的记录。您可以清晰看见是哪个 Host 触发了向国内 223.5.5.5 的查询。

方法 2：结合 Chrome/Edge 开发者工具 (F12) 追溯网页内泄露 URL

打开浏览器的 F12 开发者工具 → 切换到 Network (网络) 选项卡：

1. 筛选状态或搜索泄露域名（例如测试网站返回的泄露子域名）。
2. 查看该请求的 Initiator (发起程序) 列，它会直接显示是网页中的哪一行 JS 代码发起的泄露请求。
